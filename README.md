# MultiFarm Pro - Powerleveling

## 🔥 Description
Application de gestion de powerleveling pour les donjons Dofus.
Permet la gestion des commandes, des paiements et des devis.

## 📁 Structure
- `PL.html` - Interface principale de gestion
- `admin.html` - Panneau d'administration
- `client.html` - Consultation de devis et paiement

## 🚀 Fonctionnalités
- Gestion des commandes avec filtres
- Suivi des paiements
- Création et gestion de devis
- Export PDF
- Intégration Discord
- Mode clair/sombre

## 📦 Installation
1. Clonez le dépôt
2. Ouvrez `PL.html` dans votre navigateur
3. Les données sont stockées en local
